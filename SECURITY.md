# Política de Segurança

## Dados sensíveis

Este aplicativo lida com dados de alunos (nome, matrícula, frequência). Embora seja offline, recomendamos:

- Nunca compartilhar o backup do banco de dados com terceiros
- Usar autenticação biométrica sempre que disponível
- Manter o dispositivo físico seguro

## Reportando vulnerabilidades

Se você encontrar uma vulnerabilidade de segurança, **não** abra uma issue pública. Envie um e-mail para [seu-email] ou abra uma issue **privada** no GitHub (se disponível).

## Atualizações de segurança

Versões futuras podem incluir:
- Criptografia de dados em repouso
- Logs de auditoria
- Autenticação em dois fatores (futuro)
