# Contribuindo para o Frequência Escolar

Primeiro, obrigado por considerar contribuir! 🎉

## Como contribuir

1. **Fork** o repositório
2. Crie uma branch para sua feature (`git checkout -b feature/nova-funcionalidade`)
3. Commit suas alterações (`git commit -m 'feat: adiciona nova funcionalidade'`)
4. Push para a branch (`git push origin feature/nova-funcionalidade`)
5. Abra um **Pull Request**

## Diretrizes

- Siga o padrão de commits **Conventional Commits** (`feat:`, `fix:`, `docs:`, etc.)
- Mantenha o código limpo e bem comentado
- Atualize o CHANGELOG.md se adicionar uma nova feature
- Certifique-se de que o app compila e roda no Android 7.0+

## Reportar bugs

Use a aba **Issues** e preencha o template:
- Descreva o problema
- Passos para reproduzir
- Versão do Android e dispositivo
- Logs de erro (se houver)
